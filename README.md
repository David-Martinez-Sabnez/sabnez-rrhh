# Sabnez RRHH

Plataforma de Recursos Humanos desarrollada por Sabnez Consulting SAS utilizando SAP CAP (Cloud Application Programming Model).

## Funcionalidades

- 👥 Administración de empleados
- 🏠 Gestión de Home Office
- 📊 Reporte administrativo de Home Office
- 🔐 Seguridad basada en XSUAA
- ☁️ Despliegue en SAP BTP Cloud Foundry
- 🗄️ PostgreSQL (Neon)

## Arquitectura

SAP CAP
├── app/
│   ├── empleadosui
│   ├── homeofficeui
│   └── homeofficeadminui
├── srv/
├── db/
└── scripts/

## Tecnologías

- SAP CAP
- SAP Fiori Elements
- SAPUI5
- Node.js
- PostgreSQL
- SAP BTP
- Cloud Foundry
